### **Название задачи:** ADR-2: Передача актуальных ставок по депозитам в кол-центры
### **Автор:** Архитектурный комитет банка "Стандарт"
### **Дата:** 01.10.2025
### **Функциональные требования**

|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :---: | :--- | :--- | :--- |
| UC1 | Сотрудник кол-центра, Система кол-центра, АБС | Получение актуальных ставок сотрудником внутреннего кол-центра | 1. Сотрудник открывает карточку клиента в своей Системе.  2. Система кол-центра в реальном времени запрашивает и отображает актуальные ставки по депозитам из АБС. |
| UC2 | Система партнёрского кол-центра, АБС | Получение актуальных ставок партнёрским кол-центром | 1. Ежедневно в определенное время АБС автоматически формирует файл с актуальными ставками.  2. АБС передает этот файл в информационную систему партнёра по безопасному каналу. |

### **Нефункциональные требования**

|**Код**|**Требование**|
| :---: | :--- |
| +R1 | Взаимодействие с внутренним кол-центром должно происходить через защищенный REST API. |
| +R2 | Передача файла партнёру должна осуществляться по безопасному протоколу (например, SFTP). |
| R1 | Процесс выгрузки файла должен быть надежным и включать систему оповещения в случае сбоя. |
| P1 | Ответ API со ставками для внутреннего кол-центра не должен превышать 500 мс. |

### **Решение**

Решение основано на развитии "Сервиса Ставок", проектируемого в АБС. Сервис будет иметь два интерфейса для решения двух разных задач:

1.  **REST API** для синхронного предоставления данных внутренним системам в реальном времени.
2.  **Модуль пакетной выгрузки** для асинхронной передачи данных внешним партнерам, которые не могут использовать API.

### **Альтернативы**

1.  **Предоставление партнёру доступа к API.**
    * *Причина отказа:* Партнёр технологически не готов к такой интеграции.
2.  **Ручная отправка файла по почте.**
    * *Причина отказа:* Небезопасно, ненадежно, создает ненужную операционную нагрузку и риск человеческой ошибки.

### **Недостатки, ограничения, риски**

* **Рассинхронизация данных:** Данные в системе партнёрского кол-центра будут обновляться только раз в сутки, что может приводить к консультации клиентов по вчерашним ставкам в случае их резкого изменения в течение дня.
